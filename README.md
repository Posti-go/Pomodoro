# Pomodoro

A lightweight macOS Pomodoro timer that lives in your menu bar. Open it when you’re ready to focus, choose how much time to add, then close the popover and let the timer run.

## Features

- Menu bar access with a compact, liquid-glass timer window
- Quick time buttons: 1 hour, 20 minutes, 10 minutes, and 5 minutes
- Start, stop, and reset controls
- Audible alarm and a “Time’s up!” menu bar indicator when the timer finishes
- About and Quit options in the menu bar context menu

## Install

1. Download [Pomodoro-macOS.zip](dist/Pomodoro-macOS.zip) from this repository.
2. Unzip it and move `Pomodoro.app` to your Applications folder.
3. Open Pomodoro from Applications. Its icon will appear in the menu bar.

## Build

Open `Pomodoro.xcodeproj` in Xcode and build the `Pomodoro` scheme for macOS.
